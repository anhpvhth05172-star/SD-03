# Giao/Kết ca (P1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng P1 nghiệp vụ giao/kết ca cho PolyShoes POS: mở ca, liên kết hóa đơn với ca, tổng hợp số liệu, kết ca + đối soát tiền mặt, lịch sử tra cứu.

**Architecture:** Bảng `ca_lam_viec` + `lich_su_ca` (SQL Server), BE Spring Boot module `/api/ca/*` tự tổng hợp từ `hoa_don` (FE không gửi tổng), stamp `id_ca_lam_viec` vào `hoaidon` khi POS checkout; FE thêm banner/modal mở-ca + modal kết-ca trong POS và màn lịch sử `/ca` dùng PaginationBar + SearchableSelect sẵn có.

**Tech Stack:** Spring Boot (JPA, SQL Server), Vue 3 + Vite, axios (http.js), Puppeteer e2e (chrome cục bộ), JUnit @SpringBootTest.

**Spec:** `docs/superpowers/specs/2026-10-21-giao-ca-design.md` — mọi ruling R1–R20 lấy từ đó; plan này không lặp lại rationale.
